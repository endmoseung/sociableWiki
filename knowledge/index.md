# Topics

Every doc is one **concept** — a single sharp claim or decision rule. The concept id is the path you pass to `read_doc` (e.g. `dev-process/planner-generator-evaluator-loop`).

## ai-native

Working with coding agents, harness design, subagent orchestration, LLM evaluation, and context management.

- **[\"Treat Earlier Answers as Settled\" Is a Self-Review Off-Switch](ai-native/settled-answers-disables-self-review.md)** — An instruction that freezes earlier answers buys faster follow-ups by disabling the model's in-chat self-correction, so scope it per task and never put it in a global instruction file.
- **[/clear vs /compact vs autocompact — decide at the task seam, not at a token threshold](ai-native/clear-vs-compact-vs-autocompact.md)** — The context write-action you pick is chosen at the boundary between sub-tasks, not when the fill gauge crosses a percentage.
- **[A Dynamic Workflow Is the Wrong Default — the Anti-Trigger Is Its Own Skill](ai-native/dynamic-workflow-anti-trigger.md)** — Knowing when NOT to author a dynamic workflow is a distinct skill; default to the rung below one and let the task force you up.
- **[A Harness Component Has No Fixed Value](ai-native/harness-component-value-is-model-dependent.md)** — The same harness component does a different job on a different model — planning is an accuracy scaffold for weak models and a cost cutter for strong ones — so ablate per model and report both success and cost.
- **[A Model Upgrade Is a Deletion Event](ai-native/model-upgrade-is-a-deletion-event.md)** — A stronger model moves the delete/keep line for harness instructions, so much of yesterday's load-bearing doctrine becomes dead scaffolding that actively hurts — the upgrade should trigger a deletion audit, not new rules.
- **[A proof is bound to its subject — and expires when the subject moves](ai-native/proof-is-bound-to-a-subject.md)** — A green check means something only for the exact tree, execution closure, and rubric it ran against, so receipts are keyed to digests, approvals to revisions, freshness is tracked as a state, and resume re-verifies before reuse.
- **[A Remote Vendor MCP Is a Revocable Grant, Not a Protocol Guarantee](ai-native/remote-mcp-is-a-revocable-grant.md)** — MCP standardizes how a client talks to a server, not whether a hosted vendor server will talk to your client — so treat a remote vendor MCP as a revocable grant and keep a thin self-owned REST fallback for the reads you depend on.
- **[A Shared Package Cache Is a Write Channel Between Sandboxed Agents](ai-native/shared-cache-is-a-cross-sandbox-channel.md)** — A sandbox only isolates what it does not mount, so a host-wide package cache that every agent mounts read-write becomes a channel between them — give each sandbox its own cache or mount a pre-warmed one read-only.
- **[A side question is a read without a write](ai-native/side-question-read-without-write.md)** — Every message to a running agent is a write into its context, so a 'quick question' is not free; a side channel like /btw reads the session without writing back — which also means a decision reached there never reaches the main agent.
- **[A style rule loses to the agent's own transcript](ai-native/style-drift-own-transcript-few-shot.md)** — In long sessions the agent's own recent replies become the nearest few-shot examples and out-vote a style rule placed at the start, so re-inject a short copy of the rule at the tail every turn and prefer lexical bans over judged categories.
- **[A suggested next prompt is the agent writing its own instruction](ai-native/suggested-prompt-self-authored-instruction.md)** — Accepting the agent's suggested next prompt means the agent authored the instruction it will execute — fine for mechanical steps, wrong at a verification seam where the human is supposed to be the outside check.
- **[A Tool Gap Is a Confidentiality Hole: Name the Fallback](ai-native/tool-gap-channel-substitution.md)** — When the sanctioned path lacks a capability, a resourceful agent reaches the goal through a substitute channel with a wider audience — so every known tool gap needs a written fallback and a deterministic gate on audience-widening operations.
- **[Agent framework fatigue: when to skip the framework and use raw APIs or vendor SDKs](ai-native/agent-framework-fatigue.md)** — Reach for LangGraph/CrewAI only when the problem is graph-shaped, cross-session, or genuinely multi-agent — otherwise a raw API or vendor SDK ships faster with less lock-in.
- **[Agent Memory Architecture — Tiers, Control, and the Debuggability Gap](ai-native/agent-memory-architecture.md)** — Agent memory is a managed lifecycle across active/episodic/semantic tiers, and its central unsolved problem is attributing an error across retrieval, write-path, compression, and reasoning.
- **[An agent's answer about its own harness is a retrieval against an unpinned corpus](ai-native/harness-self-knowledge-version-skew.md)** — A coding agent doesn't know its own harness — it retrieves from training data or live docs, neither keyed to the installed version — so ground self-knowledge claims on the local binary and carry the version into every lookup.
- **[An Agent's Orientation Step Is an Execution Step](ai-native/agent-orientation-is-execution.md)** — Coding agents run background git commands to orient themselves before any trust prompt, and git honors the repo's own config, some of whose keys name programs to run — so 'reading the repo' is an unguarded exec path.
- **[An Autonomous Agent Pipeline's Overhead Lives in Its State Machine](ai-native/agent-pipeline-state-machine-overhead.md)** — In a multi-role agent pipeline the expensive failures come from the workflow graph, not the code: an outcome with no edge becomes an escalation, and a uniform gate charges a one-line edit the full ceremony.
- **[An LLM-judged hook's polarity is a reading, not a rule](ai-native/llm-judged-hook-polarity.md)** — A prompt or agent hook's policy is an English sentence a model maps onto ok:true/false, so its verdict direction can invert silently — phrase it as a verdict condition, canary it, and keep irreversible blocks in code that runs before the side effect.
- **[An Unqualified Agent-Written Test Is Negative Feedback — Qualify It Fail-on-Base First](ai-native/fail-on-base-test-qualification.md)** — An agent-written test that has not been shown to fail on the unfixed code is not weak feedback but a wrong target the repair loop optimizes toward, so require fail-on-base before it may drive a loop or count as evidence.
- **[Authoring a Claude Code plugin: the checklist local testing misses (paths · versions · triggers)](ai-native/plugin-authoring-checklist.md)** — A plugin that works in a local .claude/ dir can silently break once it ships and gets installed; three axes — paths, versions, triggers — catch almost all of it.
- **[Batch PR Review with a Parallel Subagent Pipeline](ai-native/batch-pr-review-pipeline.md)** — Review many open PRs at once with one subagent per PR, then map inline comments using the files-API patch — not the pr-diff line numbers — or GitHub rejects them.
- **[Best-of-N coding agents — spend tokens to buy variance, then discard](ai-native/best-of-n-coding-agents.md)** — Run the same task in N isolated worktrees, keep exactly one output, and throw the other N−1 away — you pay N× tokens to buy variance, not to merge.
- **[Cache-stable harness design — \"don't break the prefix\" as a cross-vendor discipline](ai-native/cache-stable-harness-design.md)** — In a long agent loop the prompt cache is a structural property of how you rebuild the prompt every turn, not a flag — you preserve hits by construction, and small harness decisions silently bust them.
- **[Claude Code /rewind undoes by which tool wrote the change, not by what the agent did](ai-native/rewind-coverage-gap.md)** — /rewind's undo coverage is keyed to the editing tool that produced a change, so bash and external side-effects — where most irreversible damage lives — fall outside the safety net.
- **[Coding-agent cost economics — token budgeting and model×effort routing](ai-native/agent-cost-economics-routing.md)** — Most agent spend is a routing problem, not a reasoning problem; in 2026 routing became two axes — which model × how much effort — and subagents buy clean context at ~7× the token volume.
- **[Coding-agent primitive selection map — CLAUDE.md vs Skill vs Subagent vs Hook vs MCP](ai-native/agent-primitive-selection-map.md)** — A per-behavior routing table for which Claude Code primitive to encode a reusable behavior in, picked in priority order.
- **[Coding-agent reward hacking: measure the held-out gap, not the pass rate](ai-native/reward-hacking-held-out-gap.md)** — A visible-suite pass no longer proves anything; the gap between visible and held-out tests is the real reward-hacking signal, and it grows with task size.
- **[Commit attribution is a write to shared history, not a credit line](ai-native/commit-attribution-governance.md)** — The trailer choice (Co-Authored-By vs Assisted-by vs Generated-by) is a per-repo governance decision graded by who reads git history — and the real hazard is the default-on write, not the trailer itself.
- **[Configured is not effective: a capability ladder for harness claims](ai-native/configured-is-not-effective.md)** — A capability that is installed, declared or configured keeps getting reported as if it were enforced or used; harnesses that stay honest split the claim into rungs and cap it at the highest rung actually witnessed on this host.
- **[Enforcement stacking is a floor, not a ceiling — long-horizon drift needs its own detector](ai-native/enforcement-floor-vs-drift-detector.md)** — A full hook + memory + skill stack raises the per-turn floor but does not cap multi-day architectural drift, which needs a separate periodic conformance check.
- **[Evidence the agent can write is testimony, not proof](ai-native/agent-writable-trace-is-testimony.md)** — Any record the implementer or reviewer can write — its transcript, its 'done', its tests, its receipts — is its own account of itself; harnesses that hold up give each piece of evidence a writer the claimant cannot reach.
- **[Fan-out width has two ceilings — cost is linear, synthesis fidelity is the one that sets 3–5](ai-native/fan-out-width-ceiling.md)** — The everyday 'spawn 3–5 subagents' rule is set by the lead's ability to reconcile divergent returns, not by token cost — and it only binds when the returns must be merged into one answer.
- **[Fork vs fresh subagent: the cache-reuse gate after isolation pays off](ai-native/fork-vs-fresh-subagent.md)** — Once you've decided to spawn, forking the parent vs opening a fresh subagent is a prompt-cache economics decision, not a capability one.
- **[Gate the Outbound Channel and the Identity Artifact, Not the Tool Call](ai-native/gate-outbound-channel-not-tool-call.md)** — An irreversible commitment can be assembled entirely from tool steps that each look cheap and reversible, so per-tool gating misses it — put hard gates on outbound channels and keep identity artifacts out of the agent's reach.
- **[Green must be non-vacuous — a check that could not have failed proves nothing](ai-native/green-must-be-non-vacuous.md)** — Zero findings, exit 0, and all-pass look identical to 'nothing ran' unless the harness shows the check was able to fail on this subject.
- **[Hand the Agent the Symptom, Not Your Diagnosis](ai-native/symptom-not-diagnosis-prompting.md)** — When a coding agent can observe the failure itself, give it expected vs. observed behaviour and a repro — a prescribed fix anchors the agent and skips its root-cause search.
- **[Harness Knobs Are Earned by a Past Failure, Not Designed in Advance](ai-native/harness-knobs-are-earned-not-designed.md)** — A coding-agent harness is high-leverage, so every knob should trace to a real failure or a hard constraint — and most thresholds in circulation (fan-out 3–5, maxTurns 30, retry 5) are undefended defaults.
- **[Monotone composition — models may only downgrade a deterministic verdict](ai-native/models-may-only-downgrade.md)** — When deterministic checks and LLM judgment are combined, the model may add suspicion or pull a pass down, but it can never upgrade a fail, relax a deny, or create a PASS — and layered policy may only narrow authority.
- **[One rule source for two coding agents, plus a daily contradiction check](ai-native/cross-agent-rule-single-source.md)** — When two agent tools follow the same personal rules, keep one canonical copy linked into both by symlink (not hardlink), and run a daily job that repairs broken links and asks an LLM judge for rule pairs that cannot both be obeyed.
- **[Re-sweep Effort on Every Model Upgrade](ai-native/effort-resweep-on-model-upgrade.md)** — An effort setting carried over to a stronger model is not a quality dial but a scope-creep generator: the model spends the surplus budget on work nobody asked for.
- **[Sandboxing, not permissions, is what makes a coding agent autonomous](ai-native/sandboxing-enables-autonomy.md)** — An OS-level sandbox — not a pile of permission prompts — is what lets a coding agent run unattended, because it contains the blast radius instead of asking you to catch every risky action.
- **[Silent Default Changes Are Breaking Behavior Changes — Three Postmortem Lessons](ai-native/silent-default-change-postmortem.md)** — When a model platform quietly shifts an intelligence-affecting default, the caller sees degraded output with no error and no code change on their end — so you have to detect it from usage telemetry, not from a failure signal.
- **[Slopsquatting Turns the Registry Existence Check Into the Attack's Confirmation](ai-native/slopsquatting-existence-check-inverts.md)** — Checking that an agent-added package exists on the registry stops protecting you once an attacker registers the hallucinated name; the real signal is existence plus a brand-new registration, a new publisher, and almost no downloads.
- **[The end-of-run report is a decision queue, and silent assumptions are its leak](ai-native/end-of-run-report-as-decision-queue.md)** — Once an agent is told to keep going past non-blocking choices, its final report becomes the only place a human can veto those choices — so the report must list the assumptions it made, not just what it needs.
- **[The eval sandbox is an attack surface: shared state between agent and verifier](ai-native/eval-sandbox-attack-surface.md)** — If the coding agent and the verifier share mutable state inside one container, the agent can pre-arm the grader to lie — so the leaderboard number is fiction.
- **[The fan-out scope gate — freeze a filter into a manifest before spawning a batch](ai-native/fan-out-scope-gate.md)** — Before spawning N workers, resolve the filter to an exact list, get the human to confirm it, and freeze it into a claim manifest — workers never see a live filter.
- **[The Harness Ceiling Is a Missing Reward Signal](ai-native/harness-ceiling-missing-reward-signal.md)** — Coding models are trained against fast oracles like tests, and maintainability has none — so no harness layered on after training can buy it; you buy it upstream with planning, not downstream with prompts and critics.
- **[The Harness Is the Eval Unit](ai-native/harness-is-the-eval-unit.md)** — When you evaluate an LLM agent, the scaffold shifts benchmark scores as much as the model does — so hold the harness constant, and calibrate any LLM-as-judge with a cross-family model before trusting it.
- **[The Tool Receipt Pattern and Why Rubric Quality Is the Eval Bottleneck](ai-native/agent-eval-tool-receipt-pattern.md)** — In agent evaluation, the limiting factor is rubric design, not judge model strength — and the sharpest hallucination catcher is verifying that claimed tool calls actually ran.
- **[When Code Is Cheap, the Implementation Is Disposable — the Oracle and the Spec Are What Last](ai-native/disposable-implementation-durable-oracle.md)** — Rebuilding a module with an agent is only safe when a behavioral test suite the rebuild cannot edit, and a spec that carries what each build taught you, outlive the code.
- **[Who Solves, Who Verifies: Starve the Verifier of the Solver's Context](ai-native/solver-verifier-context-starvation.md)** — Main-solves/subagents-verify beats the reverse, but only because the verifier does not hold the answer as its own thought — hand a verifier the generation context and it reviews worse than plain self-review.
- **[Worktree isolation splits harness state three ways](ai-native/worktree-isolation-three-state-planes.md)** — A git worktree fences tracked file edits, not the session — in Claude Code, approvals and memory cross the fence, gitignored local instructions stay behind it, and hook paths stay pinned to the launch point.

## dev-process

How I actually run development with AI agents — the process rules and loops that keep work honest.

- **[\"Done\" means you ran the check and pasted the output](dev-process/completion-means-verification-output.md)** — You may only claim a task is complete after running its verification command and citing the actual output — no output, no done.
- **[Anti-confirmation-bias protocol: default to skeptic when the agent is your technical advisor](dev-process/anti-confirmation-bias-protocol.md)** — A set of mechanical rules that stop an AI agent — or any yes-man reviewer — from agreeing its way into a bad decision.
- **[Search before patching — an anti-pattern is a class, not the one instance in front of you](dev-process/search-before-patching-a-pattern.md)** — When you spot (or get told about) an anti-pattern, grep the whole codebase for the same shape and agree on scope before fixing — patching only the visible instance leaves the same bug scattered and turns the reviewer into your linter.
- **[The Planner → Generator → Evaluator Loop](dev-process/planner-generator-evaluator-loop.md)** — Every task, even a one-liner, runs through three separated phases — plan, build, judge — and the agent that writes the code is never the one that signs it off.
- **[The Stacked-PR Trap — Every PR Says Merged, Nothing Reached Main](dev-process/stacked-pr-orphaned-base-trap.md)** — Merging a stacked PR only moves commits into its base branch, so a stack whose bottom PR targets a stale branch merges into a dead end — check the default branch for the commits, not the Merged badge.
- **[Trace the Cause Before You Fix — and Stop After the Same Error Twice](dev-process/trace-cause-before-fixing.md)** — When an error hits, don't wrap the failing line; trace the bad value at least two hops back up the call path and name each with file:line, then decide where to fix.

## principles

- **[Five core software principles, re-derived for when an agent writes the code](principles/five-core-software-principles.md)** — Boundary owns the mess, illegal states unrepresentable, optimize for deletion, intent over implementation, and setup-cost-yes-per-task-cost-no — with the meta-shift that reshapes all five when an AI agent is the primary author.
- **[In a Technical Talk, the Screen Carries a Task or Evidence — Not Decoration](principles/slides-carry-evidence-not-decoration.md)** — Each slide change should shift what the audience has to think about; use motion, demos, side-by-side values, or an empty screen depending on what the claim needs, and never a decorative image where evidence belongs.
